Что такое HTML?

HTML — это язык разметки, который описывает структуру веб-страницы.

Важно

HTML отвечает за структуру страницы, а не за её внешний вид. За оформление обычно отвечает CSS.

Как работают теги?

HTML-страница состоит из элементов. Большинство элементов записываются с помощью открывающего и закрывающего тегов.

HTML 
<h1>Привет, мир!</h1>

<p>
    Это моя первая веб-страница.
</p>

Что здесь происходит?

<h1>

Главный заголовок страницы.

<p>

Обычный текстовый абзац.

Практика

Попробуй самостоятельно

Создай заголовок со своим именем и под ним напиши один абзац о себе. 

<h1>Меня зовут ...</h1>

<p>Я изучаю веб-разработку.</p>

Создаём первую HTML-страницу

Теперь соберём минимальную структуру настоящего HTML-документа.

Основная структура

HTML 
<!DOCTYPE html>

<html lang="ru">

<head>
    <meta charset="UTF-8">
    <title>Мой сайт</title>
</head>

<body>

    <h1>Мой первый сайт</h1>

    <p>
        Я создал эту страницу сам.
    </p>

</body>

</html>
Запомни

Всё содержимое, которое пользователь видит на странице, обычно находится внутри элемента <body>.

Задание

Создай свой документ

Создай новый HTML-файл, добавь заголовок страницы, заголовок H1 и два абзаца.

Основы CSS

CSS отвечает за внешний вид: цвета, размеры, отступы, расположение элементов и многое другое.

Добавим стиль

CSS 
body {
    background: #f5f5ff;
    font-family: Arial, sans-serif;
}

h1 {
    color: #5b3df5;
    font-size: 48px;
}

p {
    color: #555;
}

Как читать CSS?

Сначала мы выбираем элемент, например h1, а внутри фигурных скобок указываем его свойства.

color

Цвет текста.

font-size

Размер текста.

background

Фон элемента.

Практика

Измени свою страницу

Сделай цветной заголовок, измени фон страницы и увеличь размер текста.
